# Design tokens

One source of truth: `design/tokens.json`. Run `npm run tokens` after editing it; that regenerates `app/tokens.css`, which the site and this Storybook both load. `npm run check` fails if the two drift.

**Rules:** neutrals plus one violet accent; light and dark themes; never hardcode colours in a component, use the tokens. Use the theme switch in the toolbar to see both.
